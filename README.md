# May Villa Website

A web development project for the May Villa hospitality brand.

## Project overview
This repository contains a website implementation intended to present the property and provide visitors with information and contact pathways.

## Technology stack
- HTML
- CSS
- JavaScript

## Run locally
1. Clone the repository.
2. Open the primary HTML file in a browser, or serve the directory using a local static web server.
3. Check the browser console and network panel for missing assets or script errors.

## What this project demonstrates
- Structuring a multi-section website.
- Styling and layout with CSS.
- Client-side interaction with JavaScript.
- Organizing static assets for web delivery.
